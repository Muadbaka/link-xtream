# Link Xtream لسطح المكتب — نسخة Flutter (Windows)

مشغل IPTV احترافي لسطح المكتب ببروتوكول **Xtream Codes API** — واجهة عربية كاملة (RTL)، محرك تشغيل **media_kit (libmpv)** يدعم H.264 / H.265 / M3U8 / TS / MKV.

هذه النسخة مبنية بـ Flutter وتعمل كتطبيق ويندوز أصلي مستقل — دون Node.js أو متصفح.

## الميزات

- **دخول حقيقي** ببيانات اشتراكك الثلاثة (Host / اسم المستخدم / كلمة المرور) عبر `player_api.php`
- **تخزين بيانات الدخول** على الجهاز (خيار «تذكّر») — استعادة جلسة تلقائية عند فتح التطبيق، وتسجيل الخروج يمسحها نهائياً
- **البث المباشر** مع دليل البرامج (EPG) الفعلي: الآن/التالي لكل قناة + لوحة برامج كاملة
- **قائمة القنوات داخل المشغّل**: تصفّح القنوات وبدّلها أثناء التشغيل دون إغلاق المشغل، مع بحث وفلترة حسب الفئة (مفتاح `L`)
- **الأفلام** بتفاصيل كاملة (القصة، الممثلون، المدة، التقييم) + استئناف المشاهدة
- **المسلسلات** بالمواسم والحلقات + علامة «مشاهدة» + تشغيل الحلقة التالية تلقائياً
- **البحث الشامل** في القنوات والأفلام والمسلسلات دفعة واحدة
- **المفضلة** لكل نوع محتوى
- **المشاهدة المتعددة**: حتى 4 قنوات معاً في شبكة 2×2 (كتم/تشغيل صوت لكل بلاطة)
- **تسجيل حقيقي** للبث المباشر إلى القرص بصيغة TS (بدء/إيقاف من داخل المشغل)
- **الرقابة الأبوية**: رقم سري + قفل فئات محددة (يُفتح 30 دقيقة لكل إدخال)
- **مظهر داكن/فاتح** بأخضر زمردي — خط Tajawal العربي
- ملء الشاشة، تحكم كامل بالصوت، حفظ موضع المشاهدة تلقائياً

## سجل التحديثات

### v1.7.1

1. **قائمة القنوات داخل مشغل البث المباشر** — زر جديد في شريط التحكم (أو مفتاح `L`) يفتح لوحة قنوات فوق المشغل تتيح تصفح القنوات وتبديلها دون إغلاق المشغل أو الرجوع إلى الشاشة السابقة.
2. **بحث وفلترة فورية** — حقل بحث داخل اللوحة مع قائمة منسدلة لاختيار الفئة، وعدّاد للقنوات المطابقة، وتُفتح اللوحة افتراضياً على الفئة التي تحتوي على القناة الحالية.
3. **تبديل فوري للقناة** — يتم تحميل القناة الجديدة في جلسة المشغل نفسها مع الحفاظ على ملء الشاشة ووضع الصورة المصغرة، ويُظهر مؤشر «قيد التشغيل الآن» على القناة الحالية.
4. **اختصارات لوحة المفاتيح** — `L` لفتح/إغلاق القائمة من زر الشريط السفلي، `Esc` لإغلاق اللوحة أولاً، والأسهم للتنقل بين القنوات.

### v1.7.0

1. **تخطي اعتمادات نهاية الحلقة تلقائياً** — عند اقتراب نهاية الحلقة يظهر شريط «بدأت الاعتمادات» مع زر «تخطي الآن»، وانتقال تلقائي للحلقة التالية بعد 10 ثوانٍ عند معرفة موضع النهاية.
2. **تعلّم نهاية كل مسلسل** — يسجّل التطبيق موضع تجاوزك للاعتمادات (زر التخطي أو الإغلاق عند ظهور الشريط)، وبعد تكراره في حلقتين يعتمده كنهاية ثابتة للمسلسل ويطبّقه على الحلقات القادمة، فلا ينتظر عدّاد الملف الكامل الذي يشمل الموسيقى الختامية. يمكن مسح التعلّم من: الإعدادات ← التشغيل.
3. **وضع الصورة المصغّرة (PiP)** — زر جديد في شريط المشغّل (أو مفتاح `P`) يصغّر النافذة إلى 480×270 أسفل يمين الشاشة مع إبقائها دائماً في المقدمة، والخروج منه يعيد أبعاد النافذة الأصلية.
4. **تصفير موضع المشاهدة بعد تخطي الاعتمادات** — الحلقة التي تُتجاوز نهايتها تُعتبر مكتملة ولا تفتح لاحقاً على الاعتمادات.

### v1.6.6

1. **قائمة المستخدم مختصرة** — حُذف خيارا «لوحة الحساب» و«الإعدادات» من قائمة الحساب المنسدلة؛ القائمة تعرض بيانات الحساب ثم «تسجيل الخروج» فقط (تبقى الشاشتان متاحتين من القائمة الجانبية).
2. **لا وميض لشاشة الدخول عند الإقلاع** — تظهر شاشة بداية بالشعار أثناء استعادة الجلسة المحفوظة، ثم يفتح التطبيق مباشرة على الواجهة الرئيسية.
3. **إصلاح أبعاد النافذة بعد الخروج من ملء الشاشة** — حفظ الأبعاد وحالة التكبير الحقيقية واستعادتها بدقة، ومزامنة الوضع عند تبديل القنوات/الحلقات أثناء ملء الشاشة.
4. **تحسين أداء المشغّل** — تقليل تحديثات الواجهة أثناء التشغيل، وإزالة اللوحة الحاجزة عند رسائل فك الترميز غير القاتلة، مع تبديل تلقائي لمسار الصوت عند تعذّر فك ترميز الصوت.
5. **بطاقات «سجل المشاهدات» بتصميم جديد** — غلاف عريض، شارة نوع (فيلم/حلقة)، شريط تقدم، الوقت المتبقي، نسبة الإنجاز، وأزرار متابعة/تفاصيل/إزالة، مع تحويم بنفس لون عناصر القائمة الجانبية.
6. **اختيار مجلد التسجيلات** — زر «تغيير» في الإعدادات يفتح منتقي مجلدات ويندوز، يتحقق من إمكانية الكتابة، ويحفظ المسار في إعدادات التطبيق مع خيار استعادة المجلد الافتراضي.

### v1.6.1

1. **القائمة الجانبية مسطّحة** — حُذفت التصنيفات (الرئيسية/الأدوات/النظام) وظهرت العناصر التسعة قائمة واحدة مباشرة، وحُذف الطي القابل للتصنيف.
2. **«البحث الشامل» أصبح «البحث»** — في القائمة الجانبية وفي عنوان شاشة البحث.
3. **المفضلة تفتح تفاصيل العنصر** — فيلم → نافذة التفاصيل، مسلسل → نافذة المواسم والحلقات (كان المسلسل لا يفتح شيئاً)، والقناة تبقى تفتح المشغل مباشرة.
4. **بيانات المطور في قسم «حول»** — الموقع www.linkco.ly والبريد hello@linkco.ly والهاتف +218913505775 (قابلة للتحديد والنسخ).

### v1.6.0

1. **تسجيل الخروج يمسح بيانات الدخول نهائياً** — بعد الخروج لا تُستعاد الجلسة تلقائياً عند فتح التطبيق ولا تُعبّأ الحقول ببيانات قديمة؛ يبقى الخيار «تذكّر» فعّالاً طالما لم تسجّل خروجاً صريحاً.
2. **أزرار القناة التالية/السابقة** في مشغل البث المباشر (تنقّل دائري عبر قائمة القنوات).
3. **عرض المواسم في تفاصيل المسلسل** — دعم بروتوكول Xtream الذي يضع `seasons` بمستوى أعلى شقيقة لـ `info`، مع احتياط يبني المواسم من مفاتيح الحلقات إن غابت.
4. **البحث الشامل يفتح نافذة التفاصيل** الخاصة بكل نتيجة: نافذة الفيلم الكاملة أو نافذة المواسم والحلقات.
5. **حقل بحث داخل كل تبويب**: المباشر والأفلام والمسلسلات — مع زر مسح.

إصلاحات سابقة (v1.5.x): شريط التقدم الأحمر في المشغل، أيقونة التطبيق، فتح النافذة مكبّرة، خطأ 183 (مجلد ephemeral)، بقاء شريط المهام فوق ملء الشاشة.

## المتطلبات لبناء نسخة الويندوز

1. **Windows 10/11** (64-bit)
2. **Flutter SDK 3.24 أو أحدث** — حمّله من <https://docs.flutter.dev/get-started/install/windows>
3. **Visual Studio 2022** أو **Build Tools for Visual Studio** مع حمل العمل
   **«تطوير سطح المكتب باستخدام ++C»** (Desktop development with C++)
   — هذا ضروري لمترجم ويندوز الأصلي.

تحقق من جاهزيتك:

```powershell
flutter doctor
```

يجب أن يظهر سطر `[√] Visual Studio - develop Windows apps (Visual Studio Build Tools 2022)`.

## خطوات البناء

افتح **PowerShell** أو **CMD** في مجلد المشروع ثم:

```powershell
flutter pub get
flutter run -d windows      # للتشغيل التجريبي مباشرة
flutter build windows --release   # لبناء النسخة النهائية
flutter build windows --release
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer\LinkXtream.iss
```

ستجد التطبيق الجاهز في:

```
build\windows\x64\runner\Release\
```

انسخ **كامل مجلد Release** إلى أي جهاز ويندوز وشغّل `link_xtream.exe` — المجلد ذاته هو التطبيق المحمول (لا يحتاج تثبيتاً).

> ملاحظة: عند أول تشغيل قد تظهر رسالة Windows SmartScreen لأن التطبيق غير موقّع رقمياً — اضغط «معلومات إضافية» ثم «تشغيل على أي حال».

## إنشاء نسخة التثبيت (Installer)

بعد `flutter build windows --release`:

```powershell
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer\LinkXtream.iss
```
flutter build windows --release
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer\LinkXtream.iss
...

- الناتج: `dist\Link-Xtream-Setup-1.7.1.exe`
- الاسم الظاهر في ويندوز: **Link Xtream** — الإصدار **1.7.1** — الناشر **Link Co**
- المثبّت **لا يحزم أي بيانات مستخدم**؛ عند أول تشغيل تُنشأ قاعدة بيانات محلية فارغة (لا يوجد أي حساب محفوظ) في `%APPDATA%\Link Co\Link Xtream`
- التثبيت يتطلب صلاحيات مدير افتراضياً، ويمكن التثبيت للمستخدم الحالي فقط لتفادي UAC

## أين تُحفظ البيانات؟

- بيانات الدخول والإعدادات والمفضلة ومواضع المشاهدة: في إعدادات المستخدم المحلية (`shared_preferences`)
  - المسار: `%APPDATA%\Link Co\Link Xtream`
  - ملاحظة أمنية: البيانات (بما فيها كلمة المرور ورمز الرقابة الأبوية) تُحفظ محلياً **بدون تشفير**. لا تستخدم التطبيق على جهاز مشترك، ويمكن حذف بياناته بالكامل من إعدادات ويندوز عند الحاجة.
- ملفات التسجيل: `مستندات\LinkXtream\Recordings` افتراضياً
- لا شيء يُرسل لأي جهة خارجية غير خادم مزوّدك مباشرة

## معلومات تقنية

- **محرك التشغيل**: media_kit — يغلّف libmpv، لذا تعمل قنوات TS وH.265 مباشرة دون أي تحويل
- **صيغة البث المباشر**: يختار m3u8 تلقائياً إن سمح به الخادم وإلا TS
- **EPG**: `get_short_epg` لكل قناة عند عرضها (تخزين مؤقت خلال الجلسة)، مع فك تشفير Base64 للعناوين
- **التفاصيل المؤجلة**: تفاصيل الفيلم ومواسم المسلسل تُجلب عند الفتح فقط — إقلاع خفيف حتى مع آلاف العناوين
